Sprites

The Sprites editor shows a sprite file (SFF v1, v2.0 and v2.01) one sprite at a time. A cross on the workspace marks the sprite's axis. In the left panel you pick the sprite and edit its group, number and axis.

Sprites

  • Add sprites from PNG, PCX, BMP or GIF images, Change a sprite's image, Delete, Duplicate (the copy uses the same image), Resize, Crop, rotate and flip.
  • For a whole group you can rename or delete it, align the axes, or move all the axes together.
  • Save as asks which sprite file version to use.
  • Sprite explorer (the Thumbnails panel) shows the sprites of a group as thumbnails.
  • You can export sprite lists for SprMaker2 and import them back.

Palettes

The Palettes panel shows the palettes in the file and the palette of the current sprite. You can edit, move, exchange and replace colors. You can add palettes from ACT, PAL, PCX, PNG, GIF, BMP, ACO and ASE files, save them as ACT, switch them between 32 and 256 colors, and remap them. Tools > Advanced palette editor works on palettes and images side by side.

Image editor

In the image editor you edit a sprite in layers, with blend modes and ten tools: moving, selections, magic wand, color picker, pen, eraser, remap pen and paint bucket. Save image changes puts the picture back into the sprite. You can also save layers as new sprites.
