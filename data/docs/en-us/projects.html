The version in mugenversion decides which parameters and triggers the code editors accept. It also decides how the files are written.

Saving

Project > Save saves every changed file in the project. Sprite and sound files save in the background, so you can keep working while they save. The status bar shows the progress. Save as copies the whole project to another folder. In each editor, Save and Save as work on that editor's current file.

Backups and autosave

  • Project > Create backup puts the project's files in a ZIP file. Load backup restores one. You can set Options to make a backup every time you open a project.
  • Autosave (Options > General) saves changed files every few minutes. If you turn on "Only save if asynchronous mode is supported", it never freezes the window.
  • The file watcher notices when another program changes your files and asks if you want to reload them.

Run in engine

Project > Run in engine starts a M.U.G.E.N engine with your project. It uses a run configuration from Options > MUGENext, which holds the engine's executable and its parameters. In the parameters, %0 stands for the project. For the run, the project is copied into the engine folder (chars/ofs_0 and so on) with its unsaved changes. The copy is deleted when the engine closes. If the project is already inside the engine folder, it is saved first and runs from there. The engine's log shows up in the Engine Output panel.
