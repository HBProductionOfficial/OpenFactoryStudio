Getting started

The first run

The first time you start the program, it asks you to pick the interface language, a preset and a theme. The preset sets how the toolbars and panels are laid out: Classic, Clean, Neo or Ultimate. You can also import your settings from an older Fighter Factory Studio install here. You can change all of this later in Tools > Options.

The window

  • Project tabs along the top: one for each open project, plus the Welcome screen. Drag a tab to move it. When a project has unsaved changes, its tab shows a mark.
  • Main toolbar: project buttons (New, Open, Save, Close, backups, Run in engine) and the buttons that switch editors.
  • Left panel: the controls of the current editor, like the sprite fields, the code tree or the Emulator's settings. View > Left panel hides it.
  • Workspace: the editor itself, with one tab for each file open in that editor.
  • Right panel: extra tools for the editor, like palettes, thumbnails, the organizer and background controllers. During a debug session it also shows the Debug panel.
  • Bottom panels: Issues, Advanced Search, Engine Output, Debugger and Watch. Click the active tab to collapse them.
  • Status bar: shows what the editor reports (cursor, selection, encoding, errors) and the project type and version. A progress bar shows up while big files load or save in the background.

Opening a project

Project > Open opens a definitions file (.def). It can be a character, stage, screenpack (system.def), fight screen (fight.def), storyboard, font or select screen. The program figures out the type by looking at the sections in the file. Open from archive opens a project inside a ZIP file. Open single file opens just one sprite, sound, animation or code file. Your recent projects are on the Welcome screen and in Project > Open recent.

Creating a project

Project > New shows a list of project templates. A template may ask you a few questions, like a name or an author, and then it makes the files. A new project has no folder until you save it. The first time you save, it asks where to put it.

Editors

A character has seven editors: Definitions, Sprites, Animations, Commands, States, Sounds and the Emulator. Stages also have a Backgrounds editor. Each editor has its own menu. When you pick an action that belongs to an editor, the program switches to that editor first.
