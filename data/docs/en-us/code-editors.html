Definitions, Commands and States

The code editor

  • Syntax coloring by meaning (sections, parameters, values, triggers, comments), using the colors of the color set you picked.
  • Line numbers, the current line, matching brackets and section folding.
  • Parameters, controllers and triggers are completed as you type. The code toolbar has code snippets.
  • Ctrl+click a controller or trigger to see its documentation.
  • Ctrl+wheel zooms in and out. The status bar shows the encoding, and you can click it to change it.
  • Edit > Code: go to line, comment and uncomment, fold and unfold all, auto indent and auto format, and jump to the previous or next error or deprecation.

The code tree

The left panel lists the sections in the file and their parameters. Click one to move the cursor there. In the States editor, the tree groups the controllers under their states and can show where each variable is used. In the Commands editor, the organizer lists the commands.

Issues

Every file is checked as you type. The check looks for unknown sections, parameters or triggers, wrong values, missing files, and things the project's engine version doesn't have. Mistakes are underlined and listed in the Issues panel. Double-click one to go to its line.

Search

  • Quick search (Ctrl+F): find and replace in the current file. The options are regular expression (put %1, %2... in the replacement for the captures), case sensitive, backward search and circular search. In the Sprites and Sounds editors it finds group,number. In the Animations editor it finds an action's number or name.
  • Advanced Search: find and replace in the file, the open files, the project, all projects or a folder, with file patterns. Lazy syntax fix corrects common mistakes.

States tools

The State controller window inserts or edits a controller and its parameters. The Controllers panel lists templates. The PalFX editor previews palette effects. The Throw creator writes the states for a throw.
