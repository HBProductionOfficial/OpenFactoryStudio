Tools

Options

Tools > Options is where you change the settings. They cover general behavior (confirmations, autosave, backups, history, the file watcher) and the interface (language, preset, icons, style, colors, scaling, shortcuts). They also cover the code editor's display and font, the image workspace (background, crosshairs, onion skin, contact boxes) and the engine page (run configurations, the Emulator's keys and box colors). You can export your settings to a file and import them again.

Editor tools

  • Throw creator (States): writes the states for a throw after you make a few choices.
  • PalFX editor (States): previews a PalFX controller on the project's sprites and inserts it.
  • Offset viewer, Alignment tool (Animations).
  • Advanced palette editor (Tools): palettes and images side by side, with color effects.
  • Export to HTML (Tools): makes a web page of the project (moves, sprites, animations) from a layout.
  • Calculator and Clipboard container (View).

Scripts

In Tools > Script editor you write and run Lua scripts that work on the open projects. The Tools > Scripts menu lists the installed scripts. The Lua scripting document in the docs folder of the source code explains the scripting interface.
