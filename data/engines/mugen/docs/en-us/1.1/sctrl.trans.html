Trans

Overrides the blending of the player for the current tick.

Parameters

transone of: Default, None, Add, AddAlpha, Add1, Sub, requiredDefault (no change), None, Add, AddAlpha, Add1 or Sub.
alpha2 integer expressionsSource and destination weights from 0 to 256 for the additive modes.

Notes

  • In 1.1 write trans = Add with an alpha pair: the default alpha is 256,256. AddAlpha (default 256,0) and Add1 (256,128) still work but are deprecated. Sub always uses 256,256.

Example

[State 1700, Fade in]
type = Trans
trigger1 = Time < 64
trans = Add
alpha = Time * 4, 256 - Time * 4
