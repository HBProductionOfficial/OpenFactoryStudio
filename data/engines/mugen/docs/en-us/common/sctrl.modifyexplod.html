ModifyExplod

Changes the parameters of explods that already exist.

Parameters

animinteger expression, F prefix allowedNew animation (F prefix for fightfx).

It also accepts every parameter of Explod.

Notes

  • Takes the parameters of Explod. Use ID to choose the explods to change.
  • Elecbyte marks this controller as subject to change between versions.

Example

[State 1000, Fade]
type = ModifyExplod
trigger1 = Time = 30
ID = 1050
trans = Add
alpha = 128, 256
