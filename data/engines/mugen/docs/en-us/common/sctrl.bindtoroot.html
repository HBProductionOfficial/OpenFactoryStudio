BindToRoot

Keeps a helper glued to a point relative to the root (the original player). Does nothing for normal players.

Parameters

timeinteger expressionTicks the binding lasts. Default 1.
facinginteger expression1: always face the same way as the parent, -1: always face away, 0: keep the current facing. Default 0.
pos2 float expressionsX and y offset from the parent axis. Default 0,0.

Notes

  • Same parameters as BindToParent, measured from the root instead of the parent.

Example

[State 6000, Shield]
type = BindToRoot
trigger1 = 1
facing = 1
pos = 0, 0
