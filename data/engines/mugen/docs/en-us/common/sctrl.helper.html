Helper

Creates a helper: another instance of the player with its own position, state and variables, used for projectiles with logic, effects, shadows or camera tricks.

Parameters

helpertypeone of: Normal, PlayerNormal or Player. Player-type helpers are not supported; keep Normal and use ScreenBound for camera control.
namequoted textName in double quotes, used in debug output.
IDinteger expressionID used by helper(ID) redirection and NumHelper. Default 0.
pos2 float expressionsX and y creation offset, interpreted according to postype.
postypeone of: P1, P2, Front, Back, Left, RightP1 (default) or P2 axis, Front or Back screen edge, Left or Right screen edge.
facinginteger expression1 faces the same way as the player (or right with Left/Right), -1 the other way.
statenointeger expressionState the helper starts in. Default 0.
keyctrlexpression, 0 or 11 lets the helper read the command input and run the State -1 of the root.
ownpalexpression, 0 or 11 gives the helper its own palette copy, unaffected by the parent PalFX and RemapPal.
remappal2 integer expressions (1.1 and later)Palette group and item the helper uses when ownpal is set.
supermovetimeinteger expressionTicks the helper may move during a SuperPause.
pausemovetimeinteger expressionTicks the helper may move during a Pause.
size.xscalefloat expressionOverrides the [Size] constant of the same name for this helper.
size.yscalefloat expressionOverrides the [Size] constant of the same name for this helper.
size.ground.backinteger expressionOverrides the [Size] constant of the same name for this helper.
size.ground.frontinteger expressionOverrides the [Size] constant of the same name for this helper.
size.air.backinteger expressionOverrides the [Size] constant of the same name for this helper.
size.air.frontinteger expressionOverrides the [Size] constant of the same name for this helper.
size.heightinteger expressionOverrides the [Size] constant of the same name for this helper.
size.proj.doscaleinteger expressionOverrides the [Size] constant of the same name for this helper.
size.head.pos2 integer expressionsOverrides the [Size] constant of the same name for this helper.
size.mid.pos2 integer expressionsOverrides the [Size] constant of the same name for this helper.
size.shadowoffsetinteger expressionOverrides the [Size] constant of the same name for this helper.

Notes

  • Helpers have no State -2 or -3 of their own, and no State -1 unless keyctrl is set.

Example

[State 1000, Fireball]
type = Helper
trigger1 = AnimElem = 2
name = "Fireball"
ID = 1001
stateno = 1001
pos = 40, -60
postype = P1
