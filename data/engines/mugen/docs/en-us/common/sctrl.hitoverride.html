HitOverride

When the player is hit by an attack matching the attributes, it goes to the given state instead of reacting normally. Up to 8 overrides can be active.

Parameters

attrhit attribute, requiredHit attribute string of the attacks to catch.
statenointeger expression, requiredState to go to when such an attack hits.
slotinteger expressionOverride slot, 0 to 7. Default 0.
timeinteger expressionTicks the override stays; -1 until replaced. Default 1.
forceairexpression, 0 or 11 sets the get-hit values as if the player was in the air.

Notes

  • While an override is active, matching HitDefs that use p1stateno or give P2 the state data of P1 do not affect the player.

Example

[State 1500, Counter stance]
type = HitOverride
trigger1 = 1
attr = SA, NA, SA
stateno = 1510
time = 1
