VarSet

Sets a variable of the player.

Parameters

vinteger expressionNumber of the int variable (0-59).
fvinteger expressionNumber of the float variable (0-39).
valueexpressionValue to use: an int expression with v, a float expression with fv.
var(n)integer expressionShort form: var(n) = value.
fvar(n)float expressionShort form: fvar(n) = value.
sysvar(n)integer expressionShort form for system int variables (0-4), reserved for common1.cns.
sysfvar(n)float expressionShort form for system float variables (0-4), reserved for common1.cns.

Notes

  • The short form var(n) = value differs from the := assignment used inside expressions.

Example

[State 1000, Remember]
type = VarSet
trigger1 = Time = 0
var(3) = StateNo
