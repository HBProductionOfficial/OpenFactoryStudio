ExplodBindTime

Changes how long existing explods stay attached to their bind points.

Parameters

IDinteger expressionOnly explods with this ID; -1 (default) affects all of them.
timeinteger expressionNew bind time in ticks; -1 binds them until further notice. Default 1.
valueinteger expressionSame as time.

Example

[State 1000, Release]
type = ExplodBindTime
trigger1 = Time = 20
ID = 1050
time = 0
