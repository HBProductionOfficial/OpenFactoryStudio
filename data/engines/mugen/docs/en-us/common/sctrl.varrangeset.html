VarRangeSet

Sets a block of consecutive variables to the same value.

Parameters

valueinteger expressionValue for int variables.
fvaluefloat expressionValue for float variables (use one of value or fvalue).
firstinteger expressionFirst variable of the block. Default 0.
lastinteger expressionLast variable of the block. Default 59 for ints, 39 for floats.

Example

[State 5900, Reset]
type = VarRangeSet
trigger1 = RoundNo = 1
value = 0
