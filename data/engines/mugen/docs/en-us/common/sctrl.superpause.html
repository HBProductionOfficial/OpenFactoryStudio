SuperPause

Freezes everything except the player, darkens the screen and plays a charge effect, typically at the start of a super move.

Parameters

timeinteger expressionTicks the pause lasts. Default 30.
animinteger expression, S/F prefix allowedFightfx animation shown (S prefix for the player AIR file). -1 for none. Default 30.
sound2 integer expressions, S/F prefix allowedSound played, from the common sounds (S prefix for the player sounds). Default -1.
pos2 float expressionsOffset of the animation from the player axis.
darkenexpression, 0 or 10 keeps the screen bright. Default 1.
p2defmulfloat expressionTemporary defence multiplier of the targets; 0 uses the mugen.cfg value. Default 0.
poweraddinteger expressionPower added to the player.
unhittableexpression, 0 or 10 lets the player be hit during the pause. Default 1.
endcmdbuftimeinteger expression (WinMUGEN and later)As in Pause.
movetimeinteger expressionAs in Pause.
pausebgexpression, 0 or 1 (WinMUGEN and later)As in Pause.

Notes

  • A SuperPause pre-empts a running Pause, whose remaining time waits.

Example

[State 3000, Flash]
type = SuperPause
trigger1 = Time = 0
time = 40
anim = 100
sound = 20, 0
pos = 20, -60
poweradd = -1000
