IfElse

Returns the second argument when the first is non-zero, the third otherwise. All three are evaluated.

Format

IfElse(condition, if_true, if_false)

Returns

type of the returned value

Notes

  • Use IfElse when both branches have to run (for example assignments); otherwise prefer Cond.

Example

value = IfElse(Facing = 1, 10, -10)
