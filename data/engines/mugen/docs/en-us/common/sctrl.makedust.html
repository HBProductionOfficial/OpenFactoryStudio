MakeDust

Old controller that draws dust clouds. Use Explod instead.

Deprecated since 1.0.

Parameters

pos2 float expressionsPosition of the cloud relative to the player axis.
pos22 float expressionsPosition of an optional second cloud.
spacinginteger expressionTicks between clouds, at least 1. Default 3.

Example

[State 100, Dust]
type = MakeDust
trigger1 = 1
pos = -10, 0
