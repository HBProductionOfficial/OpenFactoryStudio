ProjGuarded

Old-style trigger: tells whether a projectile of the player was guarded. The ID can be appended to the name. Prefer ProjGuardedTime.

Format

ProjGuarded[ID] = value
ProjGuarded[ID] = value, op ticks

Arguments

IDOptional projectile ID written right after the name, e.g. ProjGuarded1200.
value1 to test that it happened, 0 that it did not.
op ticksOptional comparison of the ticks since it happened.

Returns

boolean (1 or 0)

Example

trigger1 = ProjGuarded1200 = 1, < 15
