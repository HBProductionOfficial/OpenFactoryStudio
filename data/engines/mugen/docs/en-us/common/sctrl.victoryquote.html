VictoryQuote

Chooses which quote of the [Quotes] group appears on the next victory screen.

Available from M.U.G.E.N 1.0.

Parameters

valueinteger expressionQuote index from 0 to 99; an invalid index picks one at random. Default -1.

Notes

  • Only the winner counts, and helpers cannot use it.

Example

[State 181, Quote]
type = VictoryQuote
trigger1 = Time = 0
value = 2
