ScreenBound

Decides for one tick whether the player is kept on screen and whether the camera follows it.

Parameters

valueexpression, 0 or 10 lets the player leave the screen, 1 keeps it inside. Default 0.
movecamera2 0/1 expressions1 lets the camera follow the player horizontally, then vertically. Default 0,0.

Example

[State 6000, Free]
type = ScreenBound
trigger1 = 1
value = 0
movecamera = 0, 0
