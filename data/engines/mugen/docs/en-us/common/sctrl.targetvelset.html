TargetVelSet

Sets the velocity of the targets.

Parameters

xfloat expressionX velocity to add.
yfloat expressionY velocity to add.
IDinteger expressionOnly targets with this id; -1 for all.

Notes

  • Same parameters as TargetVelAdd.

Example

[State 821, Launch victim]
type = TargetVelSet
trigger1 = Time = 0
x = -3
y = -6
