AppendToClipboard

Debugging aid: adds a formatted line to the player clipboard shown in debug mode (Ctrl+D), keeping the text already there.

Parameters

textquoted text, requiredMessage in double quotes, printf style: %d or %i for an integer, %f, %e or %g for a float, %% for a percent sign, \n for a new line and \t for a tab.
paramslist of expressionsUp to six expressions, one per placeholder in text, in order.

Notes

  • Same parameters and format rules as DisplayToClipboard.

Example

[State 0, Log]
type = AppendToClipboard
trigger1 = 1
text = "life %d"
params = Life
