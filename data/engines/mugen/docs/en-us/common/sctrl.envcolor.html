EnvColor

Paints the whole screen in one color. Hit sparks and explods drawn on top are still visible.

Parameters

value3 integer expressionsRed, green and blue from 0 to 255. Default 255,255,255 (white).
timeinteger expressionTicks the color stays; -1 keeps it indefinitely. Default 1.
underexpression, 0 or 1When 1, the color is drawn under the players and projectiles instead of over them. Default 0.

Example

[State 3000, White flash]
type = EnvColor
trigger1 = Time = 0
time = 3
