PlaySnd

Plays a sound from the player sound file, or from the common sound file with an F prefix.

Parameters

value2 integer expressions, F prefix allowed, requiredSound group and number. Prefix the group with F for the common sounds.
volumeinteger expression (deprecated since 1.0)Volume offset used before 1.0; ignored by 1.0 and later.
volumescalefloat expression (1.0 and later)Volume in percent, 0 to 100. Default 100.
channelinteger expressionChannel; a new sound on a busy channel stops the old one. Channel 0 is for voices and is cut when the player is hit. Default -1 (any free channel).
lowpriorityexpression, 0 or 1Non-zero: does not interrupt a sound already playing on the channel.
freqmulfloat expressionPitch multiplier. Default 1.
loopexpression, 0 or 1Non-zero loops the sound.
paninteger expressionStereo offset in pixels from the player, towards its front when positive.
abspaninteger expressionStereo offset from the centre of the screen. Do not combine with pan.

Example

[State 200, Voice]
type = PlaySnd
trigger1 = Time = 1
value = 0, 1
channel = 0
