AnimElem

Old-style trigger: true on the tick an element of the current animation starts, or compares the time spent in that element.

Format

AnimElem = n
AnimElem = n, op ticks

Arguments

nElement number (1 is the first element).
op ticksOptional comparison with the ticks since element n started, e.g. >= 2.

Returns

boolean (1 or 0)

Notes

  • The arguments must be constants. AnimElemTime is the expression-friendly alternative.

Example

trigger1 = AnimElem = 3
trigger2 = AnimElem = 5, >= 2
