HitBy

For a while, only attacks matching the given attributes can hit the player.

Parameters

valuehit attributeHit attribute string listing the attacks concerned, e.g. SCA, NA, SA. Fills the first of the two attribute slots.
value2hit attributeThe same, but fills the second slot. Use only one of value and value2 in a controller.
timeinteger expressionTicks the slot stays active. Default 1.

Notes

  • The player has two attribute slots shared with NotHitBy. A HitDef connects only if its attribute is allowed by every slot still active.

Example

[State 700, Only throws]
type = HitBy
trigger1 = 1
value = SCA, NT, ST, HT
