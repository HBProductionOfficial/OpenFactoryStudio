AfterImage

Turns on an afterimage trail: copies of earlier frames of the player are drawn behind it with their own palette effects.

Parameters

timeinteger expressionTicks the trail stays visible; -1 keeps it until stopped. Default 1.
lengthinteger expressionNumber of past frames kept in the trail buffer, at most 60. Default 20.
palcolorinteger expressionSaturation of the copies, 0 (grey) to 256 (normal colours).
palinvertallexpression, 0 or 1Non-zero inverts the colours of the copies.
palbright3 integer expressionsRed, green, blue added to the copies before palcontrast.
palcontrast3 integer expressionsRed, green, blue multipliers (256 = 1.0) applied after palbright.
palpostbright3 integer expressionsRed, green, blue added after palcontrast.
paladd3 integer expressionsRed, green, blue added again for every step back in the trail, so older copies drift further.
palmul3 float expressionsRed, green, blue multipliers (floats) applied again for every step back in the trail.
timegapinteger expressionA frame is stored in the trail buffer every timegap ticks. Default 1.
framegapinteger expressionOnly every framegap-th stored frame is drawn. Default 4.
transone of: None, Add, Add1, SubBlending of the copies: None, Add, Add1 or Sub. Default None.

Notes

  • Each copy receives palbright, palcontrast and palpostbright once, then paladd and palmul once more for every step it lies behind the newest frame.
  • Use AfterImageTime to shorten or stop a running trail.

Example

[State 1000, Trail]
type = AfterImage
trigger1 = Time = 0
time = 30
length = 12
palbright = 0, 0, 0
palcontrast = 200, 200, 256
trans = Add
