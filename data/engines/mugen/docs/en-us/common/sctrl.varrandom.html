VarRandom

Stores a random integer in an int variable.

Parameters

vinteger expression, requiredNumber of the int variable.
range2 integer expressionsLowest and highest value. With one number n the range is 0 to n. Default 0,1000.

Example

[State 0, Dice]
type = VarRandom
trigger1 = Time = 0
v = 5
range = 1, 6
