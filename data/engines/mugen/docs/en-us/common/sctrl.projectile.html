Projectile

Fires a projectile. It accepts every HitDef parameter, which describes the hit it carries, plus the projectile parameters below.

Parameters

ProjIDinteger expressionID used by the projectile triggers.
projaniminteger expressionAnimation while flying. Default 0.
projhitaniminteger expressionAnimation played when it hits. Default -1 (keep the current one).
projremaniminteger expressionAnimation played when it is removed. Defaults to projhitanim.
projcancelaniminteger expressionAnimation played when another projectile cancels it. Defaults to projremanim.
projscale2 float expressionsX and y scale, combined with proj.doscale of the [Size] group.
projremoveexpression, 0 or 10 keeps the projectile after it hits. Default 1.
projremovetimeinteger expressionTicks before automatic removal; -1 never. Default -1.
velocity2 float expressionsInitial x and y velocity.
remvelocity2 float expressionsVelocity while the removal animation plays.
accel2 float expressionsX and y acceleration.
velmul2 float expressionsVelocity multipliers applied every tick. Default 1,1.
projhitsinteger expressionHits it can deal before it is removed. Default 1.
projmisstimeinteger expressionTicks between two hits of a multi-hit projectile.
projpriorityinteger expressionClash priority: equal priorities cancel, a higher one wins and loses 1. Default 1.
projsprpriorityinteger expressionDrawing priority. Default 3.
projedgeboundinteger expressionDistance off the screen edge at which it is removed.
projstageboundinteger expressionDistance off the stage edge at which it is removed.
projheightbound2 integer expressionsLowest and highest y it may reach.
offset2 float expressionsCreation offset, relative to postype.
postypeone of: P1, P2, Front, Back, Left, RightWhat offset is measured from: P1, P2, Front, Back, Left or Right.
projshadow3 integer expressionsNon-zero draws a shadow (before 1.1: an r,g,b shadow colour).
supermovetimeinteger expressionTicks it may move during a SuperPause.
pausemovetimeinteger expressionTicks it may move during a Pause.
ownpalexpression, 0 or 1 (1.1 and later)1 makes it ignore later PalFX and RemapPal of its owner.
remappal2 integer expressions (1.1 and later)Palette group and item it is drawn with, when ownpal is set.

It also accepts every parameter of HitDef.

Notes

  • afterimage.* parameters add an afterimage trail; they work like the AfterImage parameters.
  • Projectiles created by helpers belong to the root.

Example

[State 1000, Fireball]
type = Projectile
trigger1 = AnimElem = 3
ProjID = 1000
projanim = 1005
projhitanim = 1006
velocity = 5, 0
offset = 30, -55
attr = S, SP
damage = 60, 8
animtype = Hard
guardflag = MA
pausetime = 0, 12
sparkxy = -5, 0
ground.velocity = -6
air.velocity = -4, -3
