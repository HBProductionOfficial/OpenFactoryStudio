ProjHit

Old-style trigger: tells whether a projectile of the player hit an opponent. The ID can be appended to the name. Prefer ProjHitTime.

Format

ProjHit[ID] = value
ProjHit[ID] = value, op ticks

Arguments

IDOptional projectile ID written right after the name, e.g. ProjHit1200.
value1 to test that it happened, 0 that it did not.
op ticksOptional comparison of the ticks since it happened.

Returns

boolean (1 or 0)

Example

trigger1 = ProjHit1200 = 1, < 15
