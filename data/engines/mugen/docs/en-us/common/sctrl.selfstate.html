SelfState

Like ChangeState, but returns a player held in a custom state to its own state data.

Parameters

valueinteger expression, requiredNumber of the state to enter.
ctrlexpression, 0 or 1Sets the control flag: 1 gives control, 0 removes it. Unchanged when omitted.
animinteger expressionAnimation to switch to. The animation is unchanged when omitted.

Notes

  • Same parameters as ChangeState.

Example

[State 820, Release]
type = SelfState
trigger1 = AnimTime = 0
value = 5050
