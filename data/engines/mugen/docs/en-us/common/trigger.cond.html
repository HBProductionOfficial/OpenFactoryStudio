Cond

Returns the second argument when the first is non-zero, the third otherwise. Only the chosen branch is evaluated.

Available from M.U.G.E.N 1.0.

Format

Cond(condition, if_true, if_false)

Returns

type of the returned branch

Notes

  • Bottom in the branch that is not taken does not matter, which makes Cond safer than IfElse.

Example

value = Cond(NumHelper(10) > 0, (Helper(10), Life), Life)
