HitDefAttr

Old-style trigger: compares the attribute of the active HitDef with an attribute string.

Format

HitDefAttr = attr
HitDefAttr != attr

Arguments

attrState types followed by attack classes, e.g. SC, NA, SA.

Returns

boolean (1 or 0)

Notes

  • False when no HitDef is active (move type other than A).

Example

trigger1 = HitDefAttr = SCA, HA
