HitFallSet

Changes the fall settings of the hit the player received.

Parameters

valueinteger expression-1 keeps the fall decision, 0 cancels the fall, 1 makes the player fall. Default -1.
xvelfloat expressionNew fall x velocity (as fall.xvelocity in HitDef).
yvelfloat expressionNew fall y velocity (as fall.yvelocity in HitDef).

Example

[State 5000, No fall]
type = HitFallSet
trigger1 = Time = 0
value = 0
