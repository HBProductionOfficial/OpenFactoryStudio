ChangeAnim2

Like ChangeAnim, but takes the animation from the AIR file of the player that owns the current state. Used on an opponent put into a custom state, e.g. a thrown pose.

Parameters

valueinteger expression, requiredNumber of the animation (action) to play.
eleminteger expressionElement of that animation to start from. Default 1.

Notes

  • Same parameters as ChangeAnim.

Example

[State 820, Thrown pose]
type = ChangeAnim2
trigger1 = Time = 0
value = 820
