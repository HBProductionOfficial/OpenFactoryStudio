TargetDrop

Removes targets from the target list of the player.

Parameters

excludeIDinteger expressionTargets hit with this HitDef id are kept; -1 drops every target.
keeponeexpression, 0 or 1Non-zero keeps at most one of the kept targets (useful for throws). Default 1.

Example

[State 800, One victim]
type = TargetDrop
trigger1 = Time = 0
excludeID = 800
