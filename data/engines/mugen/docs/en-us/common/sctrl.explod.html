Explod

Creates an explod: an independent animation such as a spark, dust, a projectile trail or a full-screen overlay. It replaces GameMakeAnim and MakeDust.

Parameters

animinteger expression, F prefix allowed, requiredAnimation to play. Prefix it with F to take it from the common fight effects (fightfx) instead of the player AIR file.
IDinteger expressionID used by RemoveExplod, ModifyExplod, ExplodBindTime and NumExplod.
spaceone of: Screen, Stage (1.1 and later)Screen (fixed to the screen, not affected by camera movement or zoom) or Stage (placed in the world). Default Stage.
pos2 float expressionsPosition: an offset from the bind point when the explod is bound, otherwise the creation point.
postypeone of: P1, P2, Front, Back, Left, Right, None (deprecated since 1.1)Before 1.1: what pos is measured from. P1 and P2 use that player axis; Front and Back use the screen edge P1 faces or turns away from; Left and Right use the screen corners. None (1.1) means an absolute position.
facinginteger expression1 faces the direction of positive x of pos, -1 the other way. Default 1.
vfacinginteger expression-1 draws the explod upside down. Default 1.
bindIDinteger expression (1.1 and later)Player or helper ID to follow; -1 any player, -2 no binding (default). Screen space explods cannot be bound.
bindtimeinteger expressionTicks the explod stays attached to its bind point; -1 until removed.
vel2 float expressionsInitial x and y velocity, relative to the explod facing.
velocity2 float expressionsAccepted as another name for vel.
accel2 float expressionsX and y acceleration.
random2 integer expressions (deprecated since 1.1)Random displacement range of the creation point in x and y.
removetimeinteger expressionTicks before removal. -1 never, -2 when the animation ends (default).
supermoveexpression, 0 or 1 (deprecated since WinMUGEN)Old way to keep the explod alive during a SuperPause; use supermovetime.
supermovetimeinteger expressionTicks the explod keeps animating during a SuperPause. Default 0.
pausemovetimeinteger expressionTicks the explod keeps animating during a Pause. Default 0.
scale2 float expressionsHorizontal and vertical scale. Default 1,1.
anglefloat expression (1.1 and later)Rotation in degrees.
yanglefloat expression (1.1 and later)Rotation around the vertical axis, in degrees.
xanglefloat expression (1.1 and later)Rotation around the horizontal axis, in degrees.
sprpriorityinteger expressionDrawing priority; higher values are drawn in front. Default 0.
ontopexpression, 0 or 11 draws the explod above everything, including the stage foreground. Overrides sprpriority.
shadow3 integer expressionsNon-zero draws a shadow (before 1.1 the value was an r,g,b shadow colour).
ownpalexpression, 0 or 11 keeps the explod colours independent of later PalFX and RemapPal on the player. Fightfx explods use their own palette anyway.
remappal2 integer expressions (1.1 and later)Palette group and item the explod is drawn with, when ownpal is set. -1 ignores it.
removeongethitexpression, 0 or 11 removes the explod when the player is hit.
ignorehitpauseexpression, 0 or 11 (default) keeps the explod animating while its owner is in a hit pause.
transone of: Default, None, Add, AddAlpha, Add1, SubOverrides the animation blending: Default, None, Add, AddAlpha, Add1 or Sub.
alpha2 integer expressionsSource and destination weights (0-256) for the additive modes.

Notes

  • The position of an explod bound to a player is resolved after every player has moved, so it lines up with where the player is drawn.
  • In 1.1 use space and bindID; postype and random still work but are deprecated.

Example

[State 1000, Spark]
type = Explod
trigger1 = AnimElem = 3
anim = 1050
ID = 1050
pos = 40, -60
postype = P1
bindtime = 1
removetime = -2
sprpriority = 3
