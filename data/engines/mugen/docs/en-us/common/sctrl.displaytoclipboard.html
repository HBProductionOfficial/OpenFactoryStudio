DisplayToClipboard

Debugging aid: replaces the player clipboard with a formatted message, shown in debug mode (Ctrl+D).

Parameters

textquoted text, requiredMessage in double quotes, printf style: %d or %i for an integer, %f, %e or %g for a float, %% for a percent sign, \n for a new line and \t for a tab.
paramslist of expressionsUp to six expressions, one per placeholder in text, in order.

Example

[State 0, Debug]
type = DisplayToClipboard
trigger1 = 1
text = "state %d, x velocity %f"
params = StateNo, Vel X
