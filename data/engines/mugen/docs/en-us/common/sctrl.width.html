Width

Changes the width of the player for one tick, which controls pushing against players and screen edges.

Parameters

edge2 integer expressionsFront and back distance kept from the screen edges.
player2 integer expressionsFront and back distance kept from other players.
value2 integer expressionsSets edge and player together; do not combine with them.

Example

[State 1300, Wide]
type = Width
trigger1 = 1
value = 30, 20
