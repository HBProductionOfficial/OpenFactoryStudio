Pause

Freezes the game: players and background stop updating.

Parameters

timeinteger expression, requiredTicks to pause.
movetimeinteger expressionTicks at the start during which the player may still move (and hit). Default 0.

Notes

  • The DOS versions only know time and movetime; endcmdbuftime and pausebg came with the WinMUGEN releases.

Example

[State 3000, Freeze]
type = Pause
trigger1 = Time = 0
time = 20
